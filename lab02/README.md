# Лабораторная работа 2: Классы и инкапсуляция

## Вариант: Программная инженерия

### Инварианты BankAccount
- Начальный баланс не может быть отрицательным.
- Пополнение — только на положительную сумму.
- Списание — только на положительную сумму, не превышающую остаток.
- Баланс не может стать отрицательным.

### Инварианты ProjectTask
- `id` не равен null и не пустой.
- `title` не равен null и не пустой.
- `estimatedHours` строго больше нуля.
- `status` не равен null, по умолчанию — `NEW`.
- Изменение статуса — только через `changeStatus`.
- Увеличение оценки — только через `increaseEstimate` на положительное число.
- `id` и `title` неизменяемы (`final`), сеттеры отсутствуют.
